## Stratégie de contenu LinkedIn (visibilité organique)

Fréquence recommandée : **2 posts/semaine**

### Types de posts qui fonctionnent pour un profil comme Nicolas :

**Posts techniques (portée organique forte) :**
- Tips C# / .NET récents (record types, minimal API, pattern matching)
- "Ce que j'ai appris en migrant X vers .NET 8"
- Comparatifs (SpecFlow vs Reqnroll, etc.)

**Posts formateur :**
- Retours sur une formation ("J'ai formé X devs à la Clean Architecture, voici les 3 erreurs les plus fréquentes")
- Partage de slides / exercices

**Posts IA/LLM (sujet chaud) :**
- "Comment j'utilise Claude Code dans mon workflow .NET"
- "GitHub Copilot vs Claude Code pour le dev C# — mon vrai retour"
- Automatisation de la recherche de mission (career-ops !)

**Posts carrière freelance :**
